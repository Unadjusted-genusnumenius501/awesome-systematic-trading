## 🛠️ How to use the tools

The folder contains several sub-directories. Each directory categorizes tools by their function. 

### Libraries for data analysis
These tools process historical financial data. You use them to find patterns in past price movements. Open the folder marked Libraries to see the list of available tools. Many of these tools connect to data providers. You input your preferences, and the software generates charts or reports.

### Educational resources
The Books and Tutorials folders contain guides on market theory. Start with the beginner guides to understand terms like alpha and arbitrage. These concepts help you decide which strategies fit your goals. Read these files with a PDF viewer or text editor.

### Strategy testing
Before you risk money, you must test your strategy. Use the paper trading tools. These tools simulate real market conditions without using actual currency. You can track how your chosen algorithm performs over weeks or months. This practice builds confidence in your rules.
